# Hospital Objects: An Object Library for Robotic Nursing Assistance

This project investigates the physical characteristics of hospital nursing
supplies that must be understood before robots can reliably assist with
clinical workflows. Although robotic manipulation research commonly evaluates
rigid household objects or surgical instruments, nursing supplies have a
different combination of packaging, materials, and shapes.

The study uses a Preoperative/Postanesthesia Care Unit supply closet as a case
study. Commonly used nursing items are documented and categorized according to
their materials, packaging architectures, storage practices, and manipulation
difficulties. The resulting object library captures properties that are often
missing from conventional robotics benchmarks, including:

- Multilayer packaging and objects nested inside wrappers or containers.
- Deformable materials that change shape during grasping and placement.
- Transparent or reflective surfaces that weaken visual perception.
- Thin features, narrow openings, and irregular geometries that require
  precise control.

These observations show why performance on standard object datasets does not
fully represent the challenges of nursing workflows. The project provides a
foundation for medical-supply benchmarks and for closer collaboration between
robotics engineers and nursing professionals when designing assistive systems.
